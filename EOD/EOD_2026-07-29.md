## ⚠️ Challenges Faced
*   **Corrupted LLM Payloads**: The AI model sporadically returned malformed JSON strings containing bizarre, unescaped characters (like repeating `ˏ ˏ ˏ...`). This caused standard JavaScript `JSON.parse()` to throw fatal syntax errors.
*   **Frontend Crashes & Raw JSON Rendering**: When the parser crashed, the React UI would either crash entirely or fallback to dumping raw, unformatted JSON onto the chat screen. 
*   *Solution applied*: Implemented a custom data-salvaging fallback in `CommandCenter.tsx` that bypasses `JSON.parse()` and uses RegEx to rescue the arrays, preventing crashes and guaranteeing the UI table always renders.
